# Pinterest API demo video

Demo video for the Pinterest standard-access application for eclecticmusiceventsandmore.com

- pinterest-api-demo.mp4 - 65 seconds, 1280x720 (1.78:1), 3.9 MB

What it shows, in order:

1. The site - a free community events site in Monmouth County, New Jersey, and the event page a Pin links back to
2. How the account is authenticated, in the site's settings
3. The connected Pinterest board, and the Pin created on it through the API
4. The live queue of events waiting to be pinned, each carrying Pinterest's own
   refusal: "Apps with Trial access may not create Pins in production"

Section 4 is the case for the upgrade, in Pinterest's own words, against real events.
